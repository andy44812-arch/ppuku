## 2. 시나리오 분석

3자 구도가 다른 방향으로 바뀔 경우의 시뮬레이션:

| 시나리오 | 하정우 | 한동훈 | 박민식 |
|---------|-------|-------|-------|
| **BASELINE (3자 유지)** | **94.8%** | 5.2% | 0.0% |
| 보수단일화 → 한동훈 (박민식 사퇴) | 1.9% | **98.1%** | - |
| 보수단일화 → 박민식 (한동훈 사퇴) | **90.0%** | - | 10.0% |
| 한동훈 모멘텀 (지지율 +15% 추가 상승) | 12.8% | **87.2%** | 0.0% |
| 민주 결집 (전재수 시장선거 동반효과) | **100.0%** | 0.0% | 0.0% |

### 시나리오 해석

- **보수단일화는 후보가 누구냐가 핵심**: 한동훈으로 단일화하면 압승(98%), 박민식으로 단일화하면 한동훈 표가 분산되어 오히려 민주가 이김(90%)
- **한동훈은 +15% 모멘텀만 있으면 역전 가능** — 16일 남았고 지지율 변동성 큼
- **하정우는 박민식 사퇴 시 위험** — 한동훈에게 보수 표가 결집되면 패배

## 3. 방법론

### 3-1. 사전분포 (Prior)

> "여론조사가 아예 없다고 가정할 때, 과거 데이터로만 추정한 기대 득표율"

**Step A**: 북구갑 최근 3회 총선 진보 vs 보수 가중평균
- 가중치: 2024(0.5) + 2020(0.3) + 2016(0.2)
- 결과: 진보 52.5%, 보수 46.8%

**Step B**: 보궐선거 보정 (-2%p 진보)
- 보궐선거는 투표율 하락 → 통상 진보 지지층 이탈 더 큼
- 결과: 진보 50.5%, 보수 48.7%

**Step C**: 보수 표를 한동훈/박민식으로 분할
- 한동훈 65% / 박민식 35% (여론조사상 보수층 내 한동훈 우위 반영)

**Step D**: 사전 강도 = 200 (5회 선거 ≈ 가상 표본 200명 환산)

→ 사전 평균 득표율: 하정우 50.9%, 한동훈 31.9%, 박민식 17.2%

### 3-2. 우도 (Likelihood)

부산MBC-한길리서치 (2026-05-05, n=584, 응답률 5.3%)
- 원지지율: 하정우 34.3% / 한동훈 33.5% / 박민식 21.5%
- 무응답 10.7% → 부동층 배분: 하정우 35% / 한동훈 40% / 박민식 25%
- 배분 후: 하정우 38.0% / 한동훈 37.8% / 박민식 24.2%

### 3-3. 사후분포 (Posterior)

Dirichlet-Multinomial 결합:
- 사후 alpha: 하정우 324 / 한동훈 284 / 박민식 176
- 사후 평균: 하정우 41.3% / 한동훈 36.3% / 박민식 22.4%

여론조사가 사전분포를 일부 하향 보정 → 사후 평균은 둘의 중간값

### 3-4. Monte Carlo

사후 Dirichlet에서 10,000번 샘플링 → 각 회마다 argmax = 당선자

## 4. 핵심 가정 (모델이 깨지는 지점)

이 가정 중 하나라도 크게 틀리면 결과가 달라집니다.

| 가정 | 현재 설정 | 위험도 |
|------|----------|------|
| 부동층(10.7%)이 한동훈 40% 흡수 | 보통 | 🟡 중간 |
| 보수 베이스 65%가 한동훈으로 | 보통 | 🟡 중간 |
| 폴 1회 (부산MBC) 신뢰 | 강함 | 🔴 높음 |
| 보궐 투표율 하락 -2%p 진보 | 약함 | 🟡 중간 |
| 박민식 지지층은 한동훈으로 안 옮겨감 | 강함 | 🔴 높음 |
| 사전 강도 200 (모델 confidence) | 강함 | 🟡 중간 |

특히 **"폴 1회 신뢰"가 위험** — 부산MBC 결과만 사용. 다른 여론조사기관 폴에서는 박민식이 30% 가까이 나온 경우도 있어 더 모아야 함.
