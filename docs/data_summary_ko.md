## 3. 핵심 인사이트 (예측 모델링에 반영해야 할 요인)

### 3-1. 북구갑은 "민주당이 이길 수 있는 부산 지역구"
- 보수 우세 부산에서 민주당이 3연승한 거의 유일한 지역
- 다만 대선/지방선거에서는 보수가 더 잘 나옴 → **선거 종류별 보수·진보 갭이 큼**

### 3-2. 한동훈 출마로 인한 **보수 분열**이 결정적 변수
- 2024 총선: 보수 단일 후보(서병수) 46.7% → 그래도 패배
- 2026 보궐: 박민식 21.5% + 한동훈 33.5% = 55.0% (이론상 보수 합산)
- 단, 한동훈은 무당층/중도까지 흡수 중이라 단순 합산은 부정확

### 3-3. 보궐선거 = 낮은 투표율 = 적극 지지층 영향력 ↑
- 일반적으로 민주당 지지층(2030, 4050)은 보궐에서 투표율 더 떨어지는 경향
- 단, 한동훈 효과로 보수 결집 vs 분열 양상이 미묘

### 3-4. 부산시장 동시 선거 효과
- 같은 날 부산시장 선거(전재수 vs 박형준)도 진행 → 연동 효과 발생
- 전재수가 시장 선거에서 강세이면 북구갑 민주당 지지층 결집 가능

## 5. 다음 단계 모델 후보

| 모델 | 장점 | 단점 |
|------|------|------|
| **단순 가중 평균** | 즉시 가능, 해석 쉬움 | 역동성 반영 어려움 |
| **베이지안 업데이트** | 사전확률(과거 결과) + 우도(여론조사) 결합 | 사전확률 설정 주관적 |
| **Uniform Swing** | 동별 예측 가능, 영국식 고전 모델 | 전국·지역 추세 가정 필요 |
| **회귀 모델 (Ridge/Logistic)** | 변수 다양화 가능 | 데이터 점수 부족 (n=3 총선) |
| **시뮬레이션 (Monte Carlo)** | 당선 확률 분포 산출 | 입력 분포 가정 필요 |

**1차 추천**: 베이지안 업데이트 + Monte Carlo 시뮬레이션. 과거 선거를 사전확률로, 여론조사를 우도로 사용해 후보별 득표율 분포를 추정하고, 1만번 시뮬레이션해 당선확률을 계산.
